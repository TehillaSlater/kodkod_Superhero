# Spider-Man: Rooftop Runner

A browser-based endless runner where Spider-Man dodges obstacles across the rooftops of New York, shoots webs, and faces attacks from Doc Ock and the Green Goblin.

## Getting Started

No installation or server is required. Open `index.html` in a modern web browser to play.

## Controls

| Key | Action |
| --- | --- |
| `↑` or `Space` | Jump and swing |
| `↓` | Crouch; press while airborne to descend faster |
| `X` or `Enter` | Shoot a web |
| `Space` | Restart after game over |
| `D` | Trigger a Doc Ock attack for testing |
| `G` | Trigger a Green Goblin attack for testing |

## Gameplay

- Dodge pumpkin bombs and Mysterio's drones.
- Jump over the Green Goblin's bombs and crouch to avoid Doc Ock's tentacle.
- You can carry up to five webs. Ammo is replenished automatically after each shot.
- Hitting a drone with a web awards 25 points.
- Your score increases as you play, and obstacles get faster over time.
- Doc Ock and Green Goblin attacks alternate during the game. The background also switches between day and night as your score increases.
- A collision ends the game. Press `Space` to start again.

## Project Files

- `index.html` — Game structure, score display, and alerts.
- `style.css` — Styling, animations, and character and obstacle illustrations.
- `script.js` — Game logic, controls, scoring, and collision detection.

The game is built with HTML, CSS, and JavaScript. It has no external libraries or assets.
